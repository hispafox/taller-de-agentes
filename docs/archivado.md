# Archivado de incidencias cerradas

Decidido el 14-10-2026 por el responsable de soporte y el equipo de desarrollo.

- Una incidencia cerrada se archiva a los 90 días, porque soporte revisa las cerradas cada trimestre.
- Archivar es marcarla con un campo. No se mueve ni se borra.
- El proceso se ejecuta una vez al día, de madrugada.
- Una incidencia archivada se puede reabrir, y al reabrirla deja de estar archivada.
- Las archivadas dejan de salir en el filtro de cerradas y siguen saliendo en la búsqueda.
- El día del despliegue se avisa a soporte: las cerradas antiguas se archivan de golpe.
- La API añade el campo y no cambia nada de lo que ya devolvía.
